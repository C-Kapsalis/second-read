# Coverage: source notes to skill

Where each section of the three source notes lives in Second Read. One row per
section heading; the per-dimension sub-headings of the email note
(Definition, Why It Matters, Specific Indicators x.1-x.4, Scoring Rubric,
Enhancement Patterns, Persona Sensitivity, Measurement Method, and any
dimension-specific tables) are grouped into one row per dimension, with the
sub-parts listed.

Status:

- **Applied:** the skill acts on it every run (SKILL.md, a hard check, the
  output, or the hook).
- **Reference:** written into a reference file the skill loads when the
  format or the question needs it.
- **Not applied:** deliberately left out, with the reason.

Paths are relative to `skills/second-read/`. "SKILL §3" means section 3 of
SKILL.md. Course material is paraphrased throughout.
