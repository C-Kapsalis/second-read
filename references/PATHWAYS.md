# Pathway selection: one review, several reference lenses

Select by **communicative intent and required checks**, not word count or platform. All inputs are loaded into one review. The author should not be forced through a menu unless they ask for explicit control.

| Draft's job | Load | Most useful edit operation | Reader understanding question |
|---|---|---|---|
| Explain an expert topic or essay | ESSAYS-AND-EXPLANATIONS.md | Bridge an unstated connection; move example before abstraction | What can a newcomer know by this point? |
| Make a public policy / political argument | POLICY-AND-ARGUMENTS.md | Separate observed evidence, values, and proposed action | Which premise must be accepted for the next claim to follow? |
| Tell a story | FICTION-AND-NARRATIVE.md | Reorder scene beats; preserve purposeful uncertainty | What does the scene imply without stating it? |
| Branding / email / short message | COPY-AND-BRANDING.md | Restore the intended first impression with minimal wording | What will a new reader think the offer/position is? |
| README / API / how-to / tutorial | DOCS-AND-DIATAXIS.md | Move prerequisites before steps; correct runnable details | What must the reader already have done before this step? |

Load complementary references when a text crosses formats. Example: a research-backed product launch may require copy, an explanatory article, and documentation checks. Do not infer emotion as fact or pretend that untested product behavior has been verified. When there is no meaningful edit, publish no quiz or graph.
